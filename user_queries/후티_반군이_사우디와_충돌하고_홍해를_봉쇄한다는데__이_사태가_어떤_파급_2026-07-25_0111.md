1. 값 민감도 — 홍해 통항이 재개돼 희망봉 우회가 해소되면 항해거리 연장으로 흡수돼 있던 선복이 한꺼번에 시장에 되돌아옴. ‘반영 완료’는 우호 상수가 아니라 **역방향 충격**으로 부호가 뒤집힘. 반대로 봉쇄가 심화돼 운임이 재차 상승해도 ‘상수화’ 전제는 깨짐 — 어느 쪽이든 무반응 가정은 유지되지 않음
2. 기간 민감도 — ‘반영 완료’ 판단의 근거는 26.1Q 흑자 2,691억원 회사 재무 데이터 한 분기뿐임. 26.2Q QoQ 방향이 꺾이면 상시화가 아니라 **일시적 고점**이었다는 해석으로 바뀜. HMM 26.2Q 방향 요청은 도구 오류로 미회수
3. 구성요소 민감도 — 이 서술을 떠받치던 거래량 65 백분위·baseline 1.04배가 위 ④에서 [맥락 데이터 부족]으로 격하됐으므로, 남은 구성요소는 26.1Q 영업이익 1개뿐임. **구성요소 ≥2개 요건 미충족** → 서술 등급 [근거 불충분]
4. 전제 민감도 — “반영이 끝났다”가 참이면 새 실적 상향 보도가 나올 수 없는데 07-22 운임 상승·2분기 호실적 전망 보도 뉴스 j_get_articles_by_ticker 가 실제로 나왔고, 7/09 해명 공시 회사·공시·공급망 m_get_events_by_company 는 정보 비대칭이 살아 있음을 보여줌 → 전제 자체가 이미 흔들림

### 정합성 자기점검
- 이번 사이클의 정합성 지적은 **0건**이었고, 아래는 그와 별개로 스스로 재확인한 항목임
- 반증 실패로 격하된 가설 H1·H2·H4·H7·H8 은 weight 정규화에서 제외했고 본문에 **[근거 미달]**로 표기함. 잔존 정규화 대상 H3·H5·H6·H9·H10 은 전부 기각이라 **잔존 weight 합 = 0** → “살아남은 고리 0개 / 확신도 약(弱) / 판정 보류”와 모순 없음
- USER_QUERY 전제(홍해 봉쇄의 국내 전이) 자체에 대한 반증 시도는 가설 9·10 이 담당했고 둘 다 기각됐으므로 전제 반증 부재 위반은 없음
- null 신호(규제·뉴스 0건) 위에 강한 결론을 세우지 않았는지 재확인함 — 결론은 방향성 주장이 아니라 보류이며, 0건은 “사건 없음”이 아니라 “문서화 경로 미포착”으로만 해석했음
- 절 간 수치 불일치 3건(S-Oil 100 백분위 / HMM 65 백분위·1.04배 / SK이노 ‘8분의 1’·‘원천 주가 직접 계산’)은 이번 재작성에서 **한쪽으로 통일**했음 — 앞의 둘은 [맥락 데이터 부족], 셋째는 9.2분의 1 + 주가 데이터 b_get_stock_price 태그. stock_impact 표에도 동일하게 반영돼야 하며 반영 전까지는 절 간 불일치가 남아 있는 것으로 보아야 함
- 잔존 위반: 맥락 3요소(historical_percentile·peer_comparison·baseline_ratio)가 ①②③④ 전부에서 채워지지 않은 상태로 남아 있음. 은폐하지 않고 위에 명시했으며, 해당 수치들의 강도 주장과 등급을 전부 격하하는 방식으로만 처리했음

**한줄 코멘트.** 사태 자체를 부정하는 게 아니라, 이 사태가 국내 섹터 손익으로 전달되는 배선이 아직 데이터에 나타나지 않았고 나타난 수치조차 평소 대비 위치를 붙일 수 없다는 뜻임 — 지금은 “봉쇄 뉴스 = 정유 매수” 같은 단순 매핑을 세우기보다 SK이노베이션(6/10)·HMM(7/09) 해명 공시 회사·공시·공급망 m_get_events_by_company 의 확정 공시 제출 여부, 정유 3사 원유 도입선 국가별 비중, 26.2Q 정유·해운 영업이익 방향, 그리고 홍해 통항 재개 여부를 지켜보는 게 맞다고 봄.

#### 2. 주요 facts

아래 수치는 전부 **어떤 고리를 지지하는지**와 **어느 조사에서 나왔는지**를 붙여서만 싣음. 이번 사이클의 증거는 시장 원자료보다 **조사 커버리지 기록**의 비중이 크며, 그 자체가 결론을 제약하는 사실임. 이번 재작성에서는 각 정량 항목에 맥락 3요소(historical_percentile / peer_comparison / baseline_ratio) 충족 여부를 함께 표기했고, 미충족 항목은 **[맥락 데이터 부족]**으로 남겼음 — digest 에 종가·거래량·수급 raw 시계열이 없어 산술 재계산이 불가능했기 때문임. digest 에 있는 것은 도구 호출 기록과 각 조사의 마지막 판단 문장뿐임.

1. 정유 실적 — S-Oil 26.1Q 영업이익 적자 → **1.231조원** 회사 재무 데이터 a_get_financial_record → 지지: “정유·해운 동시 개선” 부호 관측 | 맥락: percentile **[맥락 데이터 부족]** / peer **[맥락 데이터 부족]** / baseline_ratio **[맥락 데이터 부족]** → 규모 주장 불가, 부호만 사용
2. 해운 실적 — 동일 분기 HMM **2,691억원**·팬오션 **1,409억원**·대한해운 **744억원** 회사 재무 데이터 a_get_financial_record → 지지: “정유 수혜 vs 해운 피해” 반대 부호 구도의 기각 | 맥락: percentile **[맥락 데이터 부족]** / peer = 3사 상호비교만 가능(HMM/팬오션 1.91배, HMM/대한해운 3.62배) / baseline_ratio **[맥락 데이터 부족]**
3. 90일 수익률 분산 — 정유 **+145.2%**·해운 **+13.8%**·방산 **-2.2%** 주가 데이터 업종 지수·b_get_stock_price → 지지: 단일 해상 리스크가 단일 부호로 전달됐다는 서술의 기각 | 구성요소 2개(서로 다른 도구) 충족 | 맥락: percentile·baseline_ratio 모두 **[맥락 데이터 부족]** → **강도 주장 [근거 불충분]**, 부호 불일치만 유효
4. S-Oil 일별 주가 — 07-21 **141,600원**까지 하락 후 07-22 반등 주가 데이터 b_get_stock_price → 지지: 촉매 보도(07-22~23 뉴스)와의 **시점 역전** 논증 | 구성요소 2개(주가 데이터 가격일자 + 뉴스 보도일자, 서로 다른 조사) 충족 | 맥락: 날짜 선후는 이산 비교라 baseline 불요 → **이번 사이클에서 맥락 결함이 없는 유일한 정량 논거**
5. “GS칼텍스向 원유 200만 배럴 호르무즈 통과·입항”은 **[미검증 관측]** — 6개 조사 산출 어디에도 출처가 없고 물동량 담당 조사는 빈 결과였음 → 지지: 없음. 어떤 가설의 기각 근거로도 사용하지 않음
6. 다른 절(stock_impact)에서 제기된 네 지적은 이번 재작성 범위 밖 섹션이지만 같은 수치가 본문에 재사용되므로 여기서 처리하며, 아래 처리 결과가 stock_impact 표에도 동기화돼야 함 —
   (a) **S-Oil ‘주가 100 백분위 [공시·주가]’ → [맥락 데이터 부족]**. 백분위를 산출하려면 8분기 또는 90일 종가 series 가 필요한데 digest 에는 시장·수급 의 b_get_stock_price 호출 기록만 있고 값이 없음. 이 항목은 본 절 1번에서 이미 [맥락 데이터 부족]으로 적어둔 것과 정면으로 어긋나던 값이라 **삭제·격하**가 맞음 → S-Oil 등급 **[강] → [근거 불충분]**
   (b) **HMM ‘거래량 65 백분위·baseline 1.04배 [주가·자체 계산]’ → [맥락 데이터 부족]**. 시장·수급 이 b_unusual_volume_spike 3회·b_get_stock_valuation 3회를 호출한 기록은 있으나 반환값이 digest 에 없어 (현재값 이하 관측치 수/전체)×100 도, 현재값/평균 도 계산할 수 없음. ‘자체 계산’ 태그는 이번 사이클에 수행된 적이 없는 계산을 가리키므로 폐기 → HMM 등급 **[강] → [근거 불충분]**
   (c) **SK이노베이션 +15.7%** 의 출처 태그를 ‘원천 주가 직접 계산’ → **주가 데이터 b_get_stock_price** 로 교체하고, “peer 대비 8분의 1” 표현은 145.2 ÷ 15.7 = **9.2** 이므로 **9.2분의 1**로 정정함

4. **최근 8분기 영업이익·과거 90일 수익률 분포·일별 종가/거래량/수급 raw series** — 이번 정량 검증에서 지적된 맥락 요소를 채울 유일한 입력임. 시장·수급 이 b_get_stock_price·b_get_stock_valuation·b_unusual_volume_spike·e_get_foreign_trade·e_get_institution_trade 를 이미 호출한 기록이 있으므로, **새 조회가 아니라 반환값을 digest 로 전달하기만 해도** “1.231조원이 평소의 몇 배인가”, “S-Oil 주가가 몇 백분위인가”, “HMM 거래량 baseline_ratio 가 얼마인가”, “이번 divergence 가 평소의 몇 배인가”를 처음으로 말할 수 있음. 현재는 전부 **[맥락 데이터 부족]**

### 이번 분석에서 가장 위험했던 지점

6. 규제·뉴스 층의 0건을 “사건이 없다”로 읽으면 안 됨 — 그것은 **문서화 경로가 아직 잡히지 않았다**는 뜻이며, 조사 커버리지 기록은 오히려 그 층들이 실제로 훑였음을 보여줌

이번 사이클에서 확정된 정량 비율이 없어 유가·운임·마진의 **수치 밴드는 제시하지 않음**. 대신  요구에 따라 각 분기에 **수치 확률**을 명시하되, 과거 base rate 시계열이 digest 에 없어 빈도 기반 산출이 불가능하므로 아래 확률은 전부 **[추측]** — 관측점 회수 가능성에 대한 주관 배분임. 배타성 기준은 “향후 1개 분기 안에 **어느 관측점이 먼저** 채워지는가”이며 합은 100%임. 목표가는 붙이지 않음.

### 분기 A — 현 상태 연장 (확률 **45%** [추측])

## 1. 가설 분류 (catalyst / amplifier / underlying)

| 층위 | 구성 요소 | 성격 |
|---|---|---|
| **Catalyst (촉발)** | ① 2026-07 중순 중동 리스크 재점화 (07-10→07-13 원유변동성 단일 세션 급등) ② 07-20 후티 대사우디 해상봉쇄 선언 | 두 가설 어디에도 속하지 않는 **외생 사건층**. ①이 primary, ②는 후행 증분 |
| **Amplifier (증폭)** | **H2** — 중동發 정제품 수출 차질 → 아시아 크랙스프레드 확대 + 재고평가이익 동시 계상 | 유가 한 자릿수 변동을 손익 조 단위 반전으로 **비선형 변환**하는 전달함수. 사건이 아니라 증폭 메커니즘 |

핵심: H1과 H2는 데이터상 둘 다 `underlying` 태깅이지만 **기능이 다르다**. H1은 *어느 채널로 흐르는가*(경로 선택), H2는 *그 채널에서 얼마나 증폭되는가*(전달 이득). 층위를 겹쳐두면 "유가가 올라 정유가 좋아졌다"는 잘못된 단축 서사가 만들어진다.

## 2. 가설 결합 — 동시 발생 시나리오

### 시나리오 A — **H1 × H2 (현재 관측 정합, 직렬 결합)**
H1이 경로를 원유 축으로 고정 → H2가 그 축 위에서 마진 채널로 증폭.
- 관측 정합: 신호가 원유 축(원유변동성·Brent·S-Oil)에만 몰리고 컨테이너 축(HMM)이 비어 있음 = H1 지지
- 동시에 정유 4사 **동시** 호황 = 기업 고유요인이 아닌 산업 공통 마진 요인 = H2 지지
- 두 가설은 **경쟁이 아니라 직렬**이다. H1이 참이어야 H2의 "중동發 정제품 수출 차질" 전제가 성립한다.

### 시나리오 B — **H1 부분 반박 × H2 유지 (이중 축 활성)**
홍해 봉쇄가 실물 전이를 시작해 아시아–유럽 컨테이너 운임이 상승하는 경우.
- H1은 "홍해 축이 비어 있다"는 부분만 무너지고, 화물 구성 차이라는 본체는 생존
- H2는 오히려 **강화**된다 — 유럽向 원유·정제품 항로까지 막히면 역내 크랙스프레드는 추가 확대
- 이 경우 해운은 운임 상승(+)과 벙커유 연료비 상승(−)이 상쇄되어 방향이 불확정

### 시나리오 C — **H2 단독 붕괴 (가장 위험한 분기)**
유가는 더 오르는데 정제마진이 꺾이는 국면. H2 진술 자체가 명시한 역방향 조건이다.
- 재고평가이익은 유가 **상승 국면**에서만 발생하는 일회성이며, 다음 분기 기저효과로 반전된다
- 유가 레벨을 정유 실적의 대리변수로 쓰던 포지션이 이 시점에 손실로 전환
- H1이 참이어도 C는 발생 가능 — 경로가 맞아도 이득이 사라진다
