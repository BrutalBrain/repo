# 코스모신소재 가설 교차분석

## 1. 가설 분류: Catalyst / Amplifier / Underlying

> ⚠️ 적대적 반증 후 H1·H2·H3·H10은 정규화에서 제외(REJECTED/DEMOTED)되었으며, H9(MLCC 완충 가능성)만 약한 정성 신호로 잔존한다. non-rejected 합 = 0.29 → **WEIGHT_SUM_OFF 잔존(은폐 금지)**. 아래 분류는 잔존 가설의 구조적 위치만 표시하며, 인과 단정은 불가능하다.

### 🔴 Catalyst (촉발 요인)
- **(이전 H1 — EV 캐즘 전이)** — *REJECTED*: 셀메이커 가동률·EV 판매·양극재 ASP raw 데이터 전무, 매크로 지표는 오히려 자본재 수요 증가 신호 → 단일 트리거론 미입증. **catalyst 후보로 잔존시킬 근거 없음**

### 🟠 Amplifier (증폭 요인)
- **H9** — MLCC 이형필름의 하방 완충 가능성 (역방향 amplifier = damper)
  - 잔존 weight 0.29의 유일한 가설이나, 사업비중·가동률·ASP raw 미확인 [근거 불충분]
  - **방향성 신호일 뿐 증폭 강도 정량화 불가**
- **(이전 H2 — 양극재 단일 의존)** — *DEMOTED*: 사업부문별 매출 분리(양극재 vs MLCC vs 기능성필름) 데이터 부재로 의존도 자체가 미입증

### 🟢 Underlying (기저 구조)
- **(이전 H3 — 코스모화학 수직계열화)** — *REJECTED*: FEOC 발효 시점·황산니켈 정련 capa·내부거래 raw 전무

## 2. 가설 결합 시나리오 (동시 발생)

### 시나리오 A: **단일 가설 잔존 — "결합 불가"**
- non-rejected 집합 = {H9} 단원소 → **가설 간 결합(joint) 분석 자체가 성립하지 않음**
- 이전 tail 의 'H1+H2 무방비 전이', 'H2+H4 상쇄', 'H3 지연 발현' 시나리오는 모두 **구성 가설이 REJECTED/DEMOTED 되어 폐기**
- 관측 정합 단정(예: 단일 고객 노출 57.4%)은 부문별 매출·고객별 매출 raw 부재로 **[근거 불충분]**

### 시나리오 B: **H9 단독 — "약한 댐퍼 가능성"**
- MLCC 이형필름이 AI서버·전장 수요 채널로 부분 완충할 *가능성*만 정성 제시 (확장 데이터 웹서치 단일 채널)
- 사업비중·고정비/패스스루율 raw 부재 → 완충 강도·방향 반전 여부 모두 산출 불가

### 시나리오 C: **결합 부재 → 인과 단정 보류**
- 교정된 결론대로 "정량 단정 불가" 상태 — 결합 시나리오는 데이터 회복(부문별 매출, 셀메이커 가동률, FEOC 시점, 종가·거래량 raw) 이후 재구성 필요

**2. CAPA 점유율 vs 매출 점유율의 불일치 [중][DATA_EMERGENT — 규모 불일치 패턴]**

### 1. 대안 설명

### 2. 확증 편향
